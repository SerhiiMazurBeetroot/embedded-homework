# Модуль 4.1. Домашнє завдання: UART комунікація між мікроконтролерами

Домашнє завдання: UART комунікація між мікроконтролерами

- Код і результат виконання на GitHub.
- Назва репозиторію (або гілка чи коміт меседж) повинна містити номер модуля і номер уроку.
- Посилання на репозиторій в LMS.

## Завдання

- При натисненні кнопки на стороні ESP32 змінюється стан світлодіода на стороні STM32 (Вже зробили протягом уроку)
- При натисненні кнопки на стороні STM32 змінюється стан світлодіода на стороні ESP32.
