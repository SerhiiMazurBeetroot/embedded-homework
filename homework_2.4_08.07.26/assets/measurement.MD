## Завдання 6: Порівняльна таблиця

| Метод        | Кількість хибних спрацювань          | Затримка | Складність      | Коментар                                     |
| ------------ | ------------------------------------ | -------- | --------------- | -------------------------------------------- |
| Без debounce | багато (2-5)                         | ~0       | низька          | спрацьовує на press i release                |
| Time-based   | меньше (1-2)                         | 50ms     | низька          | інколи ще спрацбовує release                 |
| State-based  | відсутні (але пару раз проскакувало) | 50ms     | середня         | release ігнорується                          |
| Polling      | 0                                    | 5ms      | середня         | стабільний програмний спосіб, без переривань |
| Hardware RC  | 0                                    | ~ 1ms    | складніша схема | ідеальний варіант                            |
