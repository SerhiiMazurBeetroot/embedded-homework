# Модуль 4.3. Зчитування складних даних: робота з регістрами та бібліотеками для I2C-сенсорів

## Домашнє завдання: I²C годинник

- Код і результат виконання на GitHub.
- Назва репозиторію (або гілка чи коміт меседж) повинна містити номер модуля і номер уроку.
- Посилання на репозиторій в LMS.

## Завдання

- Ініціалізація та коректна робота дисплея SSD1306 (128×64).
- Зчитування поточного часу з DS1307.
- Відображення часу у форматі HH:MM:SS (15:33:59).
- Відображення дати у форматі EEE DD.MM.YYYY (Sat 14.02.2026).
- Оновлення екрану не рідше 1 разу на секунду.
- Код має бути структурований (окремі функції для ініціалізації, зчитування часу, оновлення дисплея).

## Опційно:

- Підключити DS18B20. Відображати температуру під часом.
- Анімація секунд/хвилин/годин (прогресбар, спінер, крапки, тощо)
- Години та хвилини жирним текстом, все інше звичайним. Можна повторити стиль годинника типу Casio.
